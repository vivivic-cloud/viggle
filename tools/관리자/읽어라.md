# 관리자 연장 — **여기 두는 까닭**

10-10 에 상자가 다시 뜨면서 `/tmp/.../scratchpad` 가 **통째로 날아갔다.**
그 안에 지시 감시기와 장부 연장이 들어 있었다 — **사장님 지시를 못 받는 자리까지 갔다.**
그래서 다시는 안 날아가게 **저장소 안으로 옮긴다.**

| 연장 | 하는 일 |
|---|---|
| `감시둘.py` | 새 지시(`wt_asked`)나 저장소 올라옴을 잡으면 **그 자리에서 끝난다.** 끝나야 관리자가 깨어난다. |
| `감시본다.sh` | 감시가 살아 있나 센다 (`/proc` 으로 — `ps` 는 한글 명령줄을 `?` 로 적는다). |
| `장부본다.py` | 안 끝난 지시(받음·하는중)와 **전담 작업자 없는 프로그램 박스**를 센다. |

**거는 법 — 반드시 Bash 도구의 `run_in_background: true` (timeout 7200000).**
`setsid`·`nohup`·`&` 로 떼어 걸면 감시가 잡고 끝나도 **깨우는 것이 없다**(10-09 에 56분을 묵혔다).

```
python3 /home/user/viggle/tools/관리자/감시둘.py          # 걸기
bash    /home/user/viggle/tools/관리자/감시본다.sh        # 살았나
python3 /home/user/viggle/tools/관리자/장부본다.py        # 남은 지시
```

⚠ 본 눈금은 `tools/관리자/본것/지시.at` 에 남는다. 그 자리도 날아가면
`감시둘.py` 의 `처음눈금` 에서 이어 간다 — **그 값을 이따금 손으로 올려 둬라.**
⚠ `일꾼` 명단은 `장부본다.py` 안에 있다. 새 작업자를 세우면 **거기 한 줄 더한다.**


## ⚠⚠ 감시가 보는 저장소에 **박스가 쓰는 것을 다 적어라** (10-11 에 걸린 탈)

`감시둘.py` 의 `저장소` 에 **`vivivic-docs` 가 빠져 있었다.** 서류관리 작업자가
`v0.54.0`·`v0.55.0`·`v0.56.0` 을 올렸는데 **내가 셋 다 못 봤다.** 사장님께
「아직 하나도 안 올라왔습니다」 라고 적을 뻔했다 — 사실이 아니었다.

```
apps     /home/user/vivivic-apps      에이엠티·벤더피아·기계배치도·작업지시서·조혼가구·반품스캔…
cabinet  /home/user/cabinet-studio    NRS
viggle   /home/user/viggle            작업대 · 이 연장들
docs     /home/user/vivivic-docs      서류관리      ← 10-11 에 더했다
```

**새 프로그램이 딴 저장소에 서면 여기에 한 줄 더해라.** 안 그러면 그 작업자가 일해도
나는 모른다. 박스 주소(`wt_boxes` 의 「코드」 칸)를 보면 어느 저장소인지 나온다.


## ⚠⚠ 시험통을 **둘 돌리지 마라** (10-11 에 또 걸렸다. 두 번째다)

에이엠티·NRS·서류관리 시험은 저마다 **`127.0.0.1:8899`** 에 자리 서버를 띄운다.
둘이 동시에 돌면 뒤엣것이 앞엣것의 서버를 물고, **멀쩡한 시험이 빨갛게 찍힌다.**

10-11 에 내가 에이엠티 시험통을 **두 번 걸어** 놓고 잊었다. 그 통에서 `boot1` 이
「떨어짐」 으로 찍혔다. **혼자 돌리니 줄줄이 `OK` 에 나간값 0 이었다.** 40분을 버렸고,
하마터면 작업자에게 「네가 깼다」 고 할 뻔했다.

**걸기 전에 반드시 센다:**
```
pkill -f 다돌리기 ; sleep 2
ss -lntp | grep 8899 || echo "8899 비었다"
```
⚠ `ps -eo args | grep 다돌리기` 는 **안 잡힌다** — 한글 명령줄이 `?` 로 적힌다.
   살았나 보려면 **로그 파일이 자라는지**로 봐라.
⚠ 한 시험만 돌릴 수 있다 — `node 도구/다돌리기.mjs 럭스몫1 boot1`.
   통째로 돌리기 전에 **문제 되는 것만 혼자 돌려** 진짜 빨강인지 먼저 가려라.
⚠ 떨어진 것은 **그 파일을 직접 돌려 봐라**(`node boot1.mjs`). 통이 적는 까닭은
   끝줄을 주워 온 것이라 **진짜 까닭이 아닐 때가 있다**(나간값만 1 인 경우).

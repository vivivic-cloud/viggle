# 사장님 말씀 — **글자 그대로.** 바꿔 적지 마라

이 집의 모든 규칙은 여기서 나온다. 새 방은 **이것부터** 읽는다.
⚠ 요약하지 마라. 사장님 말씀은 **따옴표 안 그대로** 둔다. 내 말로 바꾸면 뜻이 변한다.

## ㄱ. 일하는 법
1. 「**코드수정시 요청내용외 절대 수정금지**」 → 시킨 것만. 그 밖은 한 줄도.
2. 「**시키지 않은걸 하면 이런 허비되는 시간이 많아지죠. 제가 이런 보안 내용이 필요할때는 분명히 고지하고 작업을 시키니 되는 방향으로 해주세요**」 (10-14) → 안 시킨 보안·막음을 만들지 마라.
3. 「**짚기 막음을 다시 넣지 마라**」 → 배송관리 짚기 막음 부활 금지.
4. 「**긁는 일을 왜 니가합니까 담당작업자가 있는데 이렇게 일을 늘려가지 마십시오**」 → 바이글은 **넘기기·재기·기다리기**만.
5. 「**야 벤더피아연동 작업을 왜 니 가했냐**」 → 전담 작업자 있는 프로그램의 코드는 **한 줄도 안 고친다**.
6. 「**작업중인거 같지도 않고**」 (10-02) → 사장님 눈에 보이는 것부터 먼저 민다. ⚠ 「작업중」 띠·점멸·시계를 만들라는 말이 **아니다**.
7. 「**아 제발 그냥 되게 해라**」 (10-09) → main 에 바로 민다. 「합치셔야 뜹니다」 는 틀린 답.

## ㄴ. 말하는 법
8. 「**말많이 하지마 니가쓴글 다 못읽어 두줄만 이야기해**」 (10-11) → 두 줄.
9. 「**한국말로 해줄래**」 (10-13)
10. 「**이런말은 내가 무슨말인지 몰라 쉽게 설명해줄자신 없으면 말도하지마**」 → 어려운 말·잰 값 늘어놓기 금지.
11. 「**질문에 답만 해줘**」 (10-17) → 물으시면 답만.
12. 「**이런거좀 안하면 안되냐 … 뭘또 내 대답을 기다린고 있어**」 → 되돌릴 수 있는 일은 묻지 말고 한다.

## ㄷ. 작업자 다루는 법
13. 「**뭐 좀 안되면 나한테 묻지말고 너한테 물어라고 좀 해줘**」 → 막히면 사장님이 아니라 바이글에게.
14. 「**야 멈춰있는 작업자들 왜 너한테 뭘자꾸 물어보다고 하냐 그냥 알아서 하라고해**」 → 작업자가 정하고 간다. 「제 답을 받은 뒤 하십시오」 금지.
15. 「**작업했으면 완료됨 세글자만 마지막 채팅 마지막 줄에 보이게 하고 안된거면 안된이유 세줄 내가 할 일 세줄만 채팅 마지막줄에 남기라고 해**」
16. 「**내가 시켰어요 작업자 채팅에 제가 직접 쓴내용은 작업후 완료상태만 보고 하게 하세요. 그곳에서 제가 직접 쓸때는 그냥 통과**」
17. 「**지시에 뭐보내면 요즘 잘 안되는경향이 있는데 … 소홀한거 아니야?**」 (10-09) → 지시를 묵히지 마라.

18. 「**금액 속성은 승인된 아이디만 볼 수 있습니다.**」 → FOB·단가·원가는 가린다. **승인된 아이디는 아직 하나도 없다.**

22. 사람 칸 제거 · 번호·주소 가림 · **원본 xlsx·PDF 는 창고에 안 올린다.**

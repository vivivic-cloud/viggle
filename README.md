# 바이글 (VIGGLE)

작업대. 폰에서 열고, 프로그램을 열고, 화면을 짚어 클로드에게 시킨다.

## 주소

**https://vivivic-cloud.github.io/viggle/**

이 하나뿐이다. 예전 맥 주소(`macbookpro:5177`)는 여기로 넘긴다.

## 어디에 무엇이 있나

자료는 파이어베이스(`vivivic-4b7ef`)에 있다. 맥은 필요 없다.

| 칸 | 무엇 |
|---|---|
| `wt_boxes/{id}` | 박스 하나 |
| `wt_chat/{박스id}` | 업무 대화 |
| `wt_dev/{자리}` | 클로드에게 남긴 지시 ← 클로드가 읽는 곳 |

`?take=1` 로 들어오면 짚어서 보낸 지시를 받아 `wt_dev` 에 쌓는다.

## 쌓인 지시 읽기

```bash
python3 tools/지시읽기.py
```

맥 없이 어디서나 돈다.
